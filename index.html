High-recall retrieval for RAG at thousands of searches per second

In retrieval-augmented generation (RAG), the model can cite only the documents that the vector search returns. KatoANN is an approximate nearest neighbor (ANN) search system that accelerates vector search with CPU matrix engines such as Intel AMX. Here it serves as the retriever over 10 million PubMed abstracts. It returns the nearest abstracts with recall above 0.99 and answers thousands of searches per second, so the searches of many agents do not pile up at the index. Pick a question to replay a recorded run, and see below how each retriever holds up as the load grows.

      When many agents search at once

      In a service that runs many agents, the throughput of vector search sets how many agents one index can serve. The searches of every agent go to the same index, and the question above alone needs five. A system keeps up while the searches stay within its capacity, but once they exceed it, the queue grows without bound and every answer waits in it. Each system runs at its lightest setting that reaches the chosen recall.
